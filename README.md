# Plate Detection Project

This project provides an end-to-end pipeline for automatic license plate detection and evaluation. It processes a dataset of vehicle images, detects license plates, and evaluates the results against annotated ground truth data.

## Features

- Loads and parses image annotations
- Processes images to detect license plates
- Evaluates detection results and generates summary statistics
- Outputs results as CSV and summary files
- Modular code structure for easy extension
